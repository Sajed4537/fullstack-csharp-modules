# ex01 — Database Structure Basics

## Objective
Comprendre la logique d’une base de données relationnelle avant de créer les tables :
- Différence entre base, table, colonne et ligne.
- Notion de clé primaire, clé étrangère et relations (1→1, 1→N, N→N).
- Comprendre comment modéliser un petit catalogue de produits.

## Steps
1. Étude du modèle conceptuel (`Categories`, `Products`, `Stock`).
2. Définition des types de relations entre tables.
3. Création du fichier `schema_conceptuel.txt` dans le dossier `src/`.

## Run
Aucun script à exécuter : ouvrir `src/schema_conceptuel.txt` pour consulter le modèle conceptuel.

## Skills
- Vocabulaire du **modèle relationnel** : base, table, colonne, ligne.
- Identification des **clés primaires** et **clés étrangères**.
- Choix du **type de relation** (1→1, 1→N, N→N) entre entités.
- Pose des bases théoriques du SQL relationnel avant toute commande `CREATE TABLE`.
