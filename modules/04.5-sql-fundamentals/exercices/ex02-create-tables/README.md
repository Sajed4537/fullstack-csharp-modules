# ex02 — Create Tables

## Objective
Créer les trois tables du catalogue (`Categories`, `Products`, `Stock`) dans SQL Server à partir du modèle défini à l’exercice 1.

## Steps
1. Connexion à SQL Server Management Studio (SSMS).
2. Création de la base `CatalogueDB`.
3. Création des tables avec leurs clés primaires et étrangères.
4. Vérification des relations et de la structure dans SSMS.
5. Sauvegarde du script `create_tables.sql` dans le dossier `src/`.

## Run
Ouvrir **SSMS**, puis exécuter `src/create_tables.sql`.

## Skills
- Création d’une **base de données** et de **tables** avec `CREATE DATABASE` / `CREATE TABLE`.
- Définition des **colonnes**, des **types** et des **contraintes**.
- Mise en place des **clés primaires** et **clés étrangères** entre tables.
